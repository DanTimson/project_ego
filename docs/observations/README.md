# Controlled observations

This directory contains preregistered black-box protocols and result sheets.

An observation is evidence only when the build, initial state, command sequence
and observed values are recorded. A remembered outcome or an unrecorded
playthrough remains a hypothesis.

## Rules

1. Record Genesis and New Horizons separately.
2. Restore an identical save or scenario before each case.
3. Use public unit/ability identities, not binary addresses.
4. Record the command sequence before running it.
5. Capture screenshots or video when practical.
6. Do not fill an ambiguous field with an inferred value.
7. Submit completed sheets before changing expected engine behaviour.
8. A result may close a binary request only when the competing interpretations
   produce distinct recorded outcomes.
