# CX-005 — aggregate public-lineage preflight report

## Contract

- **Class:** `NON_SEMANTIC_TOOLING`
- **State:** `BLOCKED`
- **Dependencies:** CX-001, CX-003 and CX-004 accepted
- **Semantic owner:** binary/governance
- **Executor:** Codex
- **Reviewer:** binary/governance
- **Runtime behaviour may change:** no

## Goal

Provide one read-only command that aggregates accepted governance checks into a
public-lineage readiness report.

## Non-goals

- Do not mark the gate passed.
- Do not edit registries or source files.
- Do not replace individual validators.

## Authoritative inputs

- accepted outputs of CX-001, CX-003 and CX-004;
- `docs/PUBLIC_LINEAGE_GATE.md`.

## Allowed output paths

- `tools/public_lineage_preflight.py`
- `tools/test_public_lineage_preflight.py`
- documentation corrections limited to this task file and queue state

## Required behaviour

- run component checks without shell-dependent parsing;
- preserve component exit codes and messages;
- provide text and JSON summaries;
- distinguish `PASS`, `FAIL`, `OPEN_POLICY` and `NOT_TRIGGERED`;
- report the gate as not triggered unless explicitly invoked for a gate stage;
- make no repository edits.

## Acceptance

```bash
python3 tools/test_public_lineage_preflight.py
python3 tools/public_lineage_preflight.py
git diff --check
```

## Escalate instead of deciding when

- a component's result cannot be mapped without changing its contract;
- the tool would need to declare a human checklist item complete.
