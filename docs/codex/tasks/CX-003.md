# CX-003 — scan transfer candidates for research-only tokens

## Contract

- **Class:** `NON_SEMANTIC_TOOLING`
- **State:** `READY`
- **Semantic owner:** binary/governance
- **Executor:** Codex
- **Reviewer:** binary/governance
- **Runtime behaviour may change:** no

## Goal

Add a configurable scanner that identifies likely research-only provenance in
candidate transferable files.

## Non-goals

- Do not sanitize files automatically.
- Do not treat every hexadecimal number as a binary address.
- Do not decide transfer eligibility.

## Authoritative inputs

- `docs/PUBLIC_LINEAGE_AUDIT.md`
- `docs/PUBLIC_LINEAGE_TRANSFER.csv`
- `docs/PUBLIC_LINEAGE_GATE.md`

## Allowed inputs

- candidate paths identified by transfer registries;
- repository text files;
- existing claim-ID conventions.

## Prohibited inputs

- raw evidence exports as implementation guidance;
- semantic comparison against decompiler output.

## Allowed output paths

- `tools/scan_transfer_surface.py`
- `tools/test_scan_transfer_surface.py`
- optional scanner configuration under `docs/` or `tools/`
- documentation corrections limited to this task file and queue state

## Required behaviour

Detect configurable patterns including:

- executable-style addresses such as `004D0AC0`;
- `FUN_`, `LAB_`, `DAT_`, `PTR_` and Ghidra-specific terminology;
- direct references to research-only files;
- decompiler-shaped identifiers.

The scanner must:

- support an allowlist with a reason for each exception;
- distinguish findings from errors;
- report file, line and pattern;
- avoid scanning `T3_RESEARCH_ONLY` material as though it were a transfer
  candidate;
- make no edits.

## Acceptance

```bash
python3 tools/test_scan_transfer_surface.py
python3 tools/scan_transfer_surface.py
git diff --check
```

## Escalate instead of deciding when

- suppressing a finding requires judging whether a comment carries necessary
  semantic evidence;
- the candidate-transfer set is ambiguous.

## Handoff

Report pattern coverage, false-positive controls and current repository findings.
