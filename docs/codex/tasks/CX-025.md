## Evidence and scope

The seeded native demo driver found that the Scenario move gate accepted a
reachable occupied endpoint. Battlefield.path permits such an endpoint for
path queries, but Battlefield.place requires a free tile. The move executor
removed the origin occupant before failing to place it, leaving a living
roster unit off the board. Seed 20260806 reached this with the Ranger moving
to (2,1) while the Guard occupied that hex. A minimal reproducer is the
Vanguard attempting to move to the Ranger's initial (0,3) tile.

Keep the shared pathfinding contract. Require a free destination in
Scenario.movement_plan before pathfinding, preserving the existing refusal
format. Advisory and execution refusal preserve both occupants, resources,
events, and RNG. Melee approach keeps its own destination selection.
