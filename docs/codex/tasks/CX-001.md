# CX-001 — validate public-lineage registries

## Contract

- **Class:** `NON_SEMANTIC_TOOLING`
- **State:** `DONE`
- **Semantic owner:** binary/governance
- **Executor:** Codex
- **Reviewer:** binary/governance
- **Runtime behaviour may change:** no

## Goal

Add a dependency-free validator for `PUBLIC_LINEAGE_TRANSFER.csv` and
`PUBLIC_TEST_TRANSFER.csv`.

## Non-goals

- Do not edit either registry automatically.
- Do not classify artifacts.
- Do not decide whether a transfer class is legally sufficient.
- Do not change engine, oracle or test behaviour.

## Authoritative inputs

- `docs/PUBLIC_LINEAGE_AUDIT.md`
- `docs/PUBLIC_LINEAGE_TRANSFER.csv`
- `docs/PUBLIC_TEST_TRANSFER.csv`
- `docs/WORK_ALLOCATION.md`

## Allowed inputs

- Repository file tree.
- Existing dependency-free style in `tools/check_deliberations.py`.

## Prohibited inputs

- Raw Ghidra exports.
- Private source-derived material.
- New interpretations of gameplay behaviour.

## Allowed output paths

- `tools/check_public_lineage.py`
- `tools/test_check_public_lineage.py`
- documentation corrections limited to this task file and queue state

## Required behaviour

The validator must:

- require the current headers and recognized `N*`/`T*` values;
- detect malformed CSV widths and duplicate exact artifact/scope rows;
- validate literal paths that should exist;
- understand semicolon-separated artifact groups;
- treat glob patterns and descriptive aggregate rows explicitly rather than
  pretending they are literal paths;
- report unknown or unclassified entries without rewriting them;
- produce deterministic, human-readable output;
- exit nonzero on structural errors and zero when only planned/open statuses
  remain.

## Acceptance

```bash
python3 tools/test_check_public_lineage.py
python3 tools/check_public_lineage.py
python3 tools/check_deliberations.py
git diff --check
```

Expected properties:

- tests use temporary synthetic registries and trees;
- no third-party Python package is required;
- no runtime implementation file changes.

## Escalate instead of deciding when

- a registry row cannot be categorized as literal, grouped, glob or aggregate
  without changing its meaning;
- a new necessity or transfer class appears;
- passing validation would require changing a classification.

## Handoff

Report all recognized row forms, validation errors covered by tests and any
registry ambiguity.
