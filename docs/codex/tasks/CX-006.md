# CX-006 — dry-run public-lineage exporter

## Contract

- **Class:** `NON_SEMANTIC_TOOLING`
- **State:** `BLOCKED`
- **Dependencies:** CX-001, CX-002, CX-003, CX-005 and an approved explicit export manifest
- **Semantic owner:** binary/governance
- **Executor:** Codex
- **Reviewer:** binary/governance
- **Runtime behaviour may change:** no

## Goal

Create a dry-run-first exporter that copies only explicitly listed public-lineage
seed artifacts into a separate destination and reports every exclusion.

## Non-goals

- Do not infer transferability from directory location.
- Do not copy `T2`, `T3`, unresolved `T4` or unclassified artifacts.
- Do not create the actual public repository.
- Do not sanitize or rewrite implementation.

## Authoritative inputs

- approved explicit export manifest;
- transfer and test inventories;
- accepted preflight tools.

## Allowed output paths

- `tools/export_public_lineage.py`
- `tools/test_export_public_lineage.py`
- a manifest schema or example under `docs/`
- documentation corrections limited to this task file and queue state

## Required behaviour

- default to dry-run;
- require an empty or nonexistent destination for actual copying;
- hash copied files;
- refuse implicit directory recursion;
- reject symlinks escaping the repository;
- emit a complete inclusion/exclusion manifest;
- fail closed on unresolved classifications.

## Acceptance

```bash
python3 tools/test_export_public_lineage.py
python3 tools/export_public_lineage.py --manifest <approved-example> --dry-run
git diff --check
```

## Escalate instead of deciding when

- no approved manifest exists;
- an artifact has mixed transfer classes;
- copying would require content transformation.
