# CX-002 — inventory unclassified tests and fixtures

## Contract

- **Class:** `NON_SEMANTIC_TOOLING`
- **State:** `DONE`
- **Semantic owner:** binary/governance
- **Executor:** Codex
- **Reviewer:** binary/governance
- **Runtime behaviour may change:** no

## Goal

Generate a deterministic report of test, oracle-test, scenario and fixture files
not covered by a specific row in `PUBLIC_TEST_TRANSFER.csv`.

## Non-goals

- Do not assign transfer classes.
- Do not edit `PUBLIC_TEST_TRANSFER.csv`.
- Do not modify tests or expected outcomes.

## Authoritative inputs

- `docs/PUBLIC_TEST_TRANSFER.csv`
- `docs/PUBLIC_LINEAGE_GATE.md`

## Allowed inputs

- `tests/`
- `oracle/test_*.py`
- `scenarios/`
- repository file tree

## Prohibited inputs

- gameplay inference;
- binary evidence not needed for path inventory.

## Allowed output paths

- `tools/inventory_public_tests.py`
- `tools/test_inventory_public_tests.py`
- generated reports under an ignored temporary/output directory only
- documentation corrections limited to this task file and queue state

## Required behaviour

- expand literal paths, semicolon groups and supported glob patterns;
- distinguish specifically classified files from the catch-all row;
- list unclassified and multiply matched files;
- sort output deterministically;
- offer machine-readable JSON and human-readable text modes;
- never edit the registry.

## Acceptance

```bash
python3 tools/test_inventory_public_tests.py
python3 tools/inventory_public_tests.py --format text
python3 tools/inventory_public_tests.py --format json
git diff --check
```

## Escalate instead of deciding when

- a path's class requires reading or interpreting its expected values;
- an inventory category cannot be represented without changing the registry
  schema.

## Handoff

Report counts by category and attach the generated inventory without committing
it unless the reviewer requests that separately.
